# ZYVORAX TEAM

All-in-one Termux toolkit with 200 modular tools.

## Quick install

```bash
curl -fsSL https://raw.githubusercontent.com/teamzyvorax/zyvorax-team/main/install.sh | bash
```

Then run:

```bash
zyvorax
```

The repository is organized as one main `zyvorax/` folder with separate tool categories.
